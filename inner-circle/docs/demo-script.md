# Five-minute demo walkthrough

1. Open the landing page; show the anonymity promise, language switcher, privacy link, and emergency disclaimer.
2. Create a student account with a demo email and password. Confirm that the sidebar shows the generated alias rather than the real name.
3. Complete the consent step and PHQ-9 / GAD-7 questions. Use non-crisis answers for the normal path; review the result and the screening-not-diagnosis disclaimer.
4. Explore the dashboard, markdown-formatted chat, resource cards, and the appointment booking interaction.
5. Show the anonymous forum board and explain that the public response projection does not expose internal identity fields.
6. Open the Fuzzy Logic Playground, run the reference input values, and inspect the output score, fired rules, and memberships.
7. Trigger "I need help now" to show the safety resources, then explain that numbers must be verified and this prototype is not an emergency service.

The professional and admin views are demonstration shells only. Explain that assigned professional access, review actions, audit trails, k-anonymity analytics, durable scheduling, and production crisis escalation are not yet connected.
